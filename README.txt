# Azuhari Personal Portfolio

A responsive red/black Japanese-inspired personal portfolio.

## Files
- `index.html` — page structure/content
- `style.css` — visual design and responsive layout
- `script.js` — smooth scrolling + active navigation
- `assets/itachi-cutout.png` — transparent character cutout

## Run
Open `index.html` directly in a browser, or upload the whole folder to your hosting.

## Customize
Edit the text in `index.html`. The TikTok link is in the Contact section.
